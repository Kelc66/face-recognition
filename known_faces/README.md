# known_faces

Put one folder per person here, named after them, with 3 to 10 photos each:

```
known_faces/
    Alice/
        1.jpg
        2.jpg
    Bob/
        photo_a.png
```

Everything in this folder except this README is **git-ignored**, so your photos are never committed.
You can also manage people and photos from the desktop app (`python app.py`).
